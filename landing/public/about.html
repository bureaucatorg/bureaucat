About BureauCat

BureauCat is an open-source, self-hosted task manager for teams whose work runs on requests and sign-offs. Purchase requests, access reviews, vendor renewals and everyday to-dos become numbered tasks, such as DEVOPS-780, that move through states you define. The default workflow includes Approval Pending, so a sign-off is a column on a board instead of an email thread.

What it does

  • Workspaces, projects and numbered tasks with priorities, assignees and followers
  • Subtasks, kanban boards, cycles and modules for planning
  • Comments with @mentions and attachments, and batched notifications in-app, by email digest or as Mattermost DMs
  • An append-only audit log where each entry is SHA-256 hash-chained to the one before it, so tampering is detectable
  • Single sign-on with Google and Zitadel, API tokens, a CLI and a documented REST API

Why it exists

Bureaucracy is not the problem; bureaucracy that stalls is. BureauCat keeps the useful parts of process, a clear owner, an explicit approval and a record of what happened, while making sure requests keep moving and nothing sits forgotten on someone's desk.

Who builds it

BureauCat is created and maintained by Ameya Shenoy, with contributions from the open-source community. The source code, issue tracker and releases live on GitHub.
